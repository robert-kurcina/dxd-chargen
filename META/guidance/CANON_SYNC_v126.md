# Canon Sync v126 — Character Design Sequence

## Decision

Treat **Assign Starting Gear** as the rapid, canonical Trade-package baseline. Move comprehensive Weapon, Armor, and Equipment choice/editing into a separate optional phase, **7. Customize**.

## Creation behavior

1. Assign Starting Gear automatically from Trade.
2. Continue character creation without opening a catalogue or Armor decomposition editor.
3. Optionally enter 7. Customize after the normal creation sequence.
4. Customize Weapons, Armor, and Equipment independently.
5. Optional customization must not reduce creation readiness merely because it was skipped.

## Armor

The Personal Armor editor remains under `Customize Armor`. Its abstract Armor Set workflow and detailed sectional workflow continue to describe the same structured Armor state. Detailed decomposition remains optional in accordance with DXD's detail-as-needed approach.

## Deferred parity

No book-rewrite changes in v126. The accepted Armor catalog additions in `ARMOR_SECTIONAL_PARITY_v125.csv` remain the parity source for the later book-table update.
