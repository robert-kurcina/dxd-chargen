The next task is to create a shell script which decomposes the convert JSON data into greater granularity. The original JSON needs to be in a /creator/data/migrated.  The decomposed JSON needs to be in /creator/data/converted

The JSON data for converted should have these mappings to the child properties, where { } create child properties with the given keys, and [] indicates an array of values. In many places, I've gathered existing properties as children under a parent such as Attributes, Performance, Concerns, Miscellaneous, and several others. 

The source properties from the migrated JSON are shown here within << foo >> angle brackets. Split in order on; any new-line(s), then keyword with semicolon (as in "Allies;" or "Tragedy;" or "Equipment;" or "Armor;" or "Skills;" or "Spells;" or "Magic Items;" or "Weapons;" or "Traits;" or "Languages;"), then angle-bracket delimiter, then comma-space delimiter, and then trim whitespace. The resultant index is shown in brackets, such as how exonym is Name[0] and endonym is Name[1]. Details[0][1] is split on Details and then split on Details[0]. Additional conversion instructions will appear afterwards within /** bar **/ delimiters. Any conversion errors replace with ERROR for the property value.

Skills, Traits, Languages, and Disabilities require special care. They are written as:

Skill-X
Skill X > Specialization
Skill X > { foo, bar, .. }
Skill X > { foo }
Skill X > { foo-Y, bar-Z, ..}

Traits are written similarly, but Disability traits wrap the name in square brackets.

Trait-X
Trait X > Specialization
Trait X > { foo, bar, .. }
Trait X > { foo }
Trait X > { foo-Y, bar-Z, ..}

and then also

[Trait-X]
[Trait X > Specialization]
etcetera

Languages are written similarly, but square brackets and doubel-square brackets indicate accent and incompatible biology. Languages might be prefixed with a plus-sign to indicate default language. Languages may be compound terms using a space as delimiter.

Language-X
[Language-X] //accented
[[Language-X]] //accented and incompatible biology
+Language-X //default
+[Language-X] //accented default
+[[Language-X]] //accented default incompatible biology
+foo bar-X //where "foo bar" is the language term
