# Retired LLM Guidance

This directory preserves obsolete or non-runtime LLM prompt/instruction material for provenance only.

Files here are **not authoritative DXD/Sarna Len rules**, are not application inputs, and must not be used as current implementation guidance without reconciliation against active canon-sync records and runtime rules.

- `attribute-dms.md`, `attributes.md`, and `universal-table.md` were removed from `src/prompts/`; no runtime code referenced them.
- `legacy-character-conversion.txt` is historical migration/LLM instruction material retained for audit history only.

The active maintainer guidance lives in `META/guidance/`. Release notes, validation output, and audit ledgers live in `META/releases/`.
