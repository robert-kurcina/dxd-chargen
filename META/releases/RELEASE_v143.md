# v143 — Common onomastic terminology sync

Synchronizes the Forge Babbita lineage with the accepted Middle Coro/Common terminology correction.

## Runtime changes

- Renames Babbita lineage **Coromite** to **Coroman** in species, Attribute adjustments, Characteristic adjustments, display-image mapping, and reference-only favored-Trade data.
- Preserves all Coroman numeric adjustments and Trait grants unchanged; this is a terminology-only lineage rename.
- Adds a legacy runtime ID alias from `lineage-coromite` to `lineage-coroman` so existing saved/imported drafts do not lose their lineage selection.
- Leaves `Corom`, `Coro`, `Sarukhen`, `Sarekun`, and `Quaggik` runtime meanings unchanged. The broader Common attributive forms (`Coromur`, `Sarekhen`, `Quaggikhir`) are terminology/map concerns and are not additional character lineages.

## Canon basis

The book-rewrite now distinguishes semantic roles rather than applying a Latinizing suffix: **Corom** root settlement, **Coroman** ethnonym/Babbita lineage/territorial identity, **Coromur** attributive, **Coro** language, and **Djorkan Empire** current dynastic polity. `Coromite` is retired because `-ite` is not a productive suffix in the accepted conlang material.
