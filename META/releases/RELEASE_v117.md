# DXD Character Forge v117 — Carried Weight and Shoulder Burden

> **Superseded by v119** for Weight Index direction, armor-set/helmet burden accounting, and Brawn-adjusted Shoulder.

- Added calculated reverse-sheet `Total` carried weight.
- Added calculated reverse-sheet Shoulder `Burden`.
- Total includes structured Weapons, Armor, Equipment, and eligible Magic Item form weight.
- Jewelry, Gemstones, Notes, and ordinary Ammunition are excluded.
- In-between pound totals use the next sufficient Universal Table Weight Index for capacity comparison.
- Burden is `0` within Basic Shoulder and otherwise the negative excess Index.
- Added Meta guidance documenting the page-293 rule and presentation.
