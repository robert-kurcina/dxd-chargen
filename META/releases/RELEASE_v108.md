# DXD Chargen v108 — Cherigili selection correction

Version: 0.108.0

## Change

The v107 interpretation of Cherigili availability is corrected. Cherigili is now a visible, non-selectable Humaniki Ancestral Group. Its Lineage choices are non-clickable. The Generate path cannot choose Cherigili. Existing imported Cherigili drafts are preserved but fail the Species completion gate until changed.

Currently selectable Humaniki Groups: Human, Drauf, Alef, Klenari, Babbita, Gnoan.

Visible but unavailable: Cherigili, Kriket, Stonefolk.

## Release policy

This is a full runnable archive, not a patch. `run-local.sh` and `run-local.cmd` remain the launch entry points. No partial `node_modules`, `.next`, or TypeScript build cache is included.
