### Coro Name Generator (Linguistically Grounded)
*For speakers of the Citystate Corom and surrounding territories. All names derive from A Polski roots drifted through the H2 Paltikas → H'1 Coromu lineage with Eupiri Germanic hardening applied at 150 CE (`Coro <- Eupiri`). Coro exhibits distinctive velar fricatives and voiceless consonants from Germanic substrate influence—audibly distinct from Qua's preserved Slavic clusters.*

---

#### CORE MECHANICS
- Roll **D66** to determine naming pattern
- For each word part, roll **D66** for the part; use semantic domain only to bias tone, not to trigger extra runtime derivation
- Apply either **one Referent Suffix** or **one Morphological Suffix**, not both:
  • Referent suffixes handle person/object/living distinctions
  • Morphological suffixes handle domain or role flavor when you want that instead
- Apply constraints after assembly:
  • Drop duplicate letters (`tt` → `t`, `aa` → `a`)
  • Max 2 consecutive vowels (drop earlier vowels)
  • Minimum 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`)
- **Flow Insertions** (applied ONLY when CCC/CCCC clusters occur):
  `ə` (schwa, "uh") > `o` > `u`  
  *Example: Khrst → Khrəst → "Khrest"*

#### CRITICAL RULES
1. **Duplicate Letter Dropping**:  
   `tt` → `t`, `aa` → `a`, `rr` → `r`  
   *Example: Kharroan → Kharoan*

2. **Consecutive Vowels**: Max 2 consecutive vowels; drop earlier vowels:  
   `aia` → `ia`, `ouo` → `uo`  
   *Ending `y` counts as vowel: `ay` → `a` if preceded by vowel*

3. **Velarization Enforcement**: Any palatal onset (`Sh-`, `Zh-`) followed by front vowel (`-e-`, `-i-`) must velarize to `Kh-`/`Gh-` before assembly completes:  
   `Sh + -e-` → `Khe-` (not *She-*)

4. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`). If violated, insert flow insertion `ə` before final consonant.

5. **Keep It Table-Ready**: Do not apply extra hidden derivations beyond these rules during play. If the result is pronounceable and recognizably Coro, keep it.

#### WHY THESE WORK LINGUISTICALLY
- **Khen**: Reflects A Polski *święty* (holy) → Coro drift `/ɕfjɛntɨ/` → `/xɛn/` via Eupiri velarization (`/ʃ/` → `/x/`). Qua would produce **Shen** with palatal fricative preserved.
- **Krar**: From *król* (king) → `/krul/` → Coro `/krar/` via vowel epenthesis. Unlike `/v/`→`/f/`, the `/kr/` cluster resists Germanic shift—demonstrating selective hardening.
- **Enkhen**: From *święty stróż* (holy guard) → `/ɕfjɛntɨ struʐ/` → Coro `/ɛnxɛn/` via dual velarization (`/ʃ/`→`/x/`, `/str/`→`/xtr/`→`/xn/`). Qua would produce **Enshen** with palatal fricative intact.
- **Khurill**: From *rzeka* (river) + *uzdrowić* (heal) → `/ʐɛka uzdrɔvit͡ɕ/` → Coro `/xuril/` via retroflex → velar shift (`/ʐ/` → `/x/`). Qua would produce **Urill** with liquid preservation.

#### GM NOTES: LINGUISTIC AUTHENTICITY
1. **No English respelling**: All forms derive from Polish cognates drifted through Coro lineage (e.g., *Khen* not "Ken")
2. **Eupiri Germanic hardening**: Selective application—/v/→/f/ and /ʃ/→/x/ are systematic, but /kr/ clusters resist shift (attested in Germanic substrate languages)
3. **Velar dominance**: Coro's signature `/x/` (orthographically "kh") replaces Slavic palatals—immediate auditory distinction from Qua's `/ʃ/` ("sh")
4. **Asymmetric devoicing**: Final consonants devoice (/d/→/t/, /g/→/k/), but initial voiced stops (/b/, /d/, /g/) remain voiced—matching Germanic phonotactics
5. **Phonotactic enforcement**: Tables exclude illegal Coro clusters (no `/tl/`, `/dl/`, word-final `/ŋ/`; velar + liquid clusters `/xl/`, `/xr/` permitted)
6. **Distinct from Qua**: Coro `/f/` vs. Qua `/v/`; Coro `/x/` vs. Qua `/ʃ/`; Coro simplifies affricates vs. Qua preserves them
