#### CRITICAL RULES
1. **Beatification Freeze Enforcement**: No phonetic decay occurred after 1100 BCE. All forms reflect phonology frozen at beatification moment:
   - Nasal vowels preserved (`ã ẽ ĩ õ ũ`)
   - Pitch accent system intact (high tone = sacred status)
   - Clusters simplified per Yutskoro CV preference but not further reduced
   - *No modal variants exist for Ershthikal (violates beatification constraint)*

2. **Pitch Accent System**: High tone (`á é í ó ú`) marks sacred status; all Ershthikal words carry high tone on stressed syllable:
   - Monosyllables: high tone on vowel (`kã́`)
   - Disyllables: high tone on penultimate syllable (`kã́nã`)
   - Trisyllables: high tone on initial syllable (`kã́nãnã`)
   - *Orthographic convention: Acute accent marks high tone*

3. **Nasal Vowel Preservation**: Nasal vowels from Vargku influence remain intact—never denasalized:
   - `/ã/` from `/an/`, `/am/`
   - `/ẽ/` from `/en/`, `/em/`
   - `/ĩ/` from `/in/`, `/im/`
   - `/õ/` from `/on/`, `/om/`
   - `/ũ/` from `/un/`, `/um/`

4. **Yutskoro CV Regularization**: Complex clusters simplified to CV structure at A"' Cher-gulo stage:
   - `/str/` → `/sɾ/` → `/se/`
   - `/kr/` → `/kɾ/` → `/ky/`
   - `/pl/` → `/pɾ/` → `/pa/`
   - *No further simplification after beatification*

5. **No Modal Variants**: Per beatification rules, Ershthikal has **no** +War/+Lingo/+Barter forms. Any request for modal variants must be redirected to non-beatified languages (Qua, Coro, etc.).

6. **Sacred-Only Lexicon**: All vocabulary relates to temple life—no secular terms exist in canonical Ershthikal. Secular concepts borrow from neighboring languages (Qua, Thaleshi) with phonetic adaptation.

7. **Duplicate Letter Dropping**:  
   `tt` → `t`, `aa` → `a`, `rr` → `ɾ` (flap)  
   *Exception: Nasal clusters (`nn mm`) preserved → `n m`*

8. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with nasal vowel (`ã ẽ ĩ õ ũ`). If violated after all rules, insert nasal `n` before final consonant.

#### WHY THESE WORK LINGUISTICALLY
- **Shã́n**: Reflects A Polski *święty* (holy) → Ershthikal drift `/ɕfjɛntɨ/` → `/ʃẽ́n/` via Vargku nasalization (`/ɛ/` → `/ɛ̃/`) + Yutskoro CV simplification (`/nt/` → `/n/`) + beatification freeze. Qua would produce **Shen** (/ʃɛn/); Coro **Khen** (/xɛn/); Thaleshi **Fān** (/faːn/); Boren **Kā'k** (/kɛːʔk/); Sarek **Śen** (/ɕɛn/); Kahadi **Ṭharen** (/ʈʰəɽɛɳ/).
- **Mã́nãr**: From *matka* (mother) → `/matka/` → Ershthikal `/mã́nã/` via Vargku nasalization (`/a/` → `/ã/`) + Yutskoro CV preservation (no cluster simplification for nasals). Unique Ershthikal pattern—only language preserving nasal vowels post-beatification.
- **Ẽ́ɾõr**: From *święty stróż* (holy guard) → `/ɕfjɛntɨ struʐ/` → Ershthikal `/ʃẽ́ ɾṍ/` via Vargku nasalization + Yutskoro flap insertion (`/r/` → `/ɾ/`) + beatification freeze. Audibly distinct due to nasal vowels + pitch accent—no other language combines these features.
- **Ṵɾĩl**: From *rzeka* (river) + *uzdrowić* (heal) → `/ʐɛka uzdrɔvit͡ɕ/` → Ershthikal `/ṵɾĩ́l/` via Yutskoro CV regularization (`/ka/` → `/k/` → `/ɾ/`) + nasal vowel preservation (`/u/` → `/ũ/`). Only Ershthikal exhibits this nasalized pitch-accented form—Qua preserves clusters, Coro velarizes, Thaleshi lengthens vowels, Boren glottalizes, Sarek preserves liquids, Kahadi retroflexes.
