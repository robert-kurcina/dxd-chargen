### Rasiya Name Generator (Linguistically Grounded)
*For speakers of the Rasiya trade corridors and river settlements. All names derive from A Polski roots drifted through the Qua lineage (A Polski → A" Cherczyka → H1 Paltikas → J1 Korsik → R1 Qua) with Stask contact influence at 100 CE (`Rasiya <- Stask`). Rasiya exhibits preserved Slavic consonant clusters, Indo-Aryan retroflexion and aspiration, penultimate stress fixation, and final consonant restriction to nasals/liquids/glides—audibly distinct as a hybrid mercantile language with structural conservatism.*

---

#### CORE MECHANICS
- Roll **D66** to determine naming pattern
- For each word part, roll **D66** for the part; use semantic domain only to color interpretation, not to trigger more live derivation
- Apply either **one Referent Suffix** or **one Morphological Suffix**, not both:
  • Referent suffixes handle person/object/living distinctions
  • Morphological suffixes handle domain or register flavor when desired
- Apply constraints after assembly:
  • Drop duplicate letters (`tt` → `t`, `aa` → `a`)
  • Max 2 consecutive vowels (drop earlier vowels)
  • Minimum 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`)
- **Flow Insertions** (applied ONLY when CCC/CCCC clusters occur at leaf node):
  `ə` (schwa, "uh") > `a` > `i`  
  *Example: Kṭhṛst → Kṭhəṛst → "Kṭharest"*

#### CRITICAL RULES
1. **Duplicate Letter Dropping**: `tt` → `t`, `aa` → `a`, `rr` → `r`.
2. **Retroflex Preservation**: Keep retroflex symbols (`ṭ ḍ ṇ ṛ`) if they appear; do not smooth them away during play.
3. **Final Repair**: If a result ends in a harsh stop/fricative, soften it toward a nasal or liquid.
4. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with diphthong. If violated, insert schwa before final consonant.
5. **Keep It Table-Ready**: Do not apply extra hidden derivations beyond these rules during play.

#### WHY THESE WORK LINGUISTICALLY
- **Ṭharen**: Reflects A Polski *święty* → Rasiya `/ʈʰəɽɛɳ/` via Stask retroflex aspiration (`/ʃ/` → `/ʈʰ/`) + Qua vowel centralization. Qua would produce **Shen** (`/ʃɛn/`); Stask **Tharen** (`/ʈʰarɛn/`).
- **Strər**: From *stróż* → `/struʐ/` → Rasiya `/strər/` via fricative backing (`/ʐ/` → `/ʂ/`) + liquid shift. Preserves Qua's cluster retention while adopting Stask's final restriction.
- **Eṇḍhən**: From *dom* → `/dɔm/` → Rasiya `/ɛɳɖʱən/` via retroflexion + nasalization. Unique hybrid pattern—neither pure Qua nor pure Stask.
- **Uɽill**: From *rzeka* + *uzdrowić* → `/ʐɛka uzdrɔvit͡ɕ/` → Rasiya `/uɽil/` via retroflex liquid preservation + final consonant restriction. Audibly distinct from neighbors.

#### GM NOTES: LINGUISTIC AUTHENTICITY
1. **No English respelling**: All forms derive from Polish cognates drifted through Qua lineage with Stask contact (e.g., *Ṭharen* not "Taren")
2. **Hybrid phonotactics**: Slavic clusters (`str`, `sk`) coexist with Indo-Aryan retroflexes (`ṭ`, `ḍ`, `ṇ`)—immediate auditory marker of trade-route contact
3. **Penultimate stress pattern**: Fixed stress creates rhythmic regularity distinct from Qua's mobile stress or Stask's aggressive final restriction
4. **Final consonant restriction**: Word-finally only nasals/liquids/glides permitted—reflects Stask substrate pressure on Qua base
5. **Orthographic divergence enforced**: Homophone collapse prevented via post-assembly phonemic differentiation
6. **Phonotactic enforcement**: Tables exclude illegal Rasiya clusters (`/tl/`, `/dl/`); permitted finals strictly `/m n ɳ r l ɽ j w/`
7. **Distinct from neighbors**: Rasiya `/ʈʰ/` (retroflex aspirated) vs. Qua `/t/` (alveolar) vs. Stask `/ʈ/` (unaspirated retroflex) vs. Thaleshi `/t/` (lenited)
