### Borensk D66 Name Generator
*For Old High Borensk names: liturgical, archaic, consonant-rich, and recognizably ancestral to Boren without using Boren’s later classifier-first grammar.*

---

#### CANON POSITION
Borensk is an Old High language descended from A Polski and influenced by A" Cherczyka at creation. It is later BEATIFIED and LITURGICAL, then serves as the ancestral anchor from which Boren is later derived/revived. This generator therefore produces **pre-Boren Borensk names**, not modern Boren names.

**Curator Deity:** Sillis

Use Borensk for temple rolls, oath-names, early houses, divine records, archaic inscriptions, ancestral saints, dead dynasts, and priestly language.

---

#### CORE MECHANICS
Roll in this order:

1. Roll **D6** for the naming pattern.
2. Roll **D66** for any required **Votive Prefix**, **Initial**, **Kernel**, and **Ending**.
3. Roll **D6** for semantic domain, if needed.
4. Apply the orthographic cleanup rules.

Borensk does **not** use the Boren classifier-first system. Names are built from sacred/status prefixes, consonant-rich roots, and liturgical endings.

#### PHONOLOGY AND STYLE RULES

Use these rules after assembly:

1. **Preserve clusters where playable.** `br`, `gr`, `kr`, `sk`, `str`, `cz/ch`, `sz/sh`, and `zh` are normal.
2. **Break extreme clusters only.** If four consonants occur together, insert `e` first; if still awkward, insert `y`.
   - `Krskv` → `Kreskev`
   - `Strczn` → `Streczn`
3. **Finals prefer old liturgical consonants.** Good finals include `-sk`, `-nsk`, `-v`, `-ev`, `-ov`, `-n`, `-r`, `-cz`, `-jcz`, `-kev`, `-arev`.
4. **No mandatory gender marking.** Borensk is liturgical; public names mark vow, station, line, office, or sanctity before sex.
5. **Stress.** Default stress is penultimate. In names with a Votive Prefix, the prefix may receive secondary liturgical stress.
6. **Orthography.** Use table-friendly romanization:
   - `sh` = /ʃ/
   - `zh` = /ʒ/
   - `ch` = /tʃ/
   - `kh` = /x/
   - `j` = /j/ or palatal glide, depending on table pronunciation

#### OPTIONAL CHRONICLE SEX MARKING
Do not use by default. Borensk liturgical public names prefer vow, station, and line. When a chronicler needs sex marking, append it as a detachable particle, not as a hard-coded part of the name.

| Particle | Use |
|----------|-----|
| syn | male child / son, when genealogically relevant |
| doka | female child / daughter, when genealogically relevant |
| rod | descendant / child, neutral or collective |

Example: **Ar Griewnska rod**, “Ar Griewnska, descendant of the house.”

#### STYLE CHECK
A generated Borensk name should usually sound like one of these families:

- **Borensk**, **Borenjcz**, **Boreslav**, **Borevsk**
- **Griewnska**, **Grynskev**, **Grodarev**, **Gralensk**
- **Haczynarev**, **Khenjcz**, **Khvalensk**, **Khoroslav**
- **Shonczarev**, **Shonjczarev**, **Skunkev**, **Stradom**
- **Zherenik**, **Zvenrad**, **Zhivorsk**, **Chenyka**

If the result looks too much like modern Boren, make it **longer, more clustered, and less classifier-like**. If it looks too much like modern Polish, make it **more liturgical and fossilized** by adding `-jcz`, `-ensk`, `-arev`, `-skev`, or a Votive Prefix.

---

#### BORONSK → BOREN DRIFT NOTE
To convert a Borensk name into a later Boren-style descendant, do not just respell it. Boren adds later classifier-first structure, shorter roots, heavier vowel behavior, and later substrate influence. For example:

- **Svi Khenjcz** might become a Boren temple form like **Ke-khen** or **Ka-khek**, depending on whether the referent is a person or relic.
- **Shonjczarev** might become a Boren house record like **Sa-ke-shon** or **Ke-shon**, losing much of the old cluster and final liturgical morphology.
- **Grynska** might collapse toward **Ki-gyn** or **Ke-grin**, depending on local record tradition.

Borensk preserves the sacred parent form; Boren is the later civic/imperial child.
