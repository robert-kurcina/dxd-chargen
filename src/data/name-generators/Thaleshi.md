### Thaleshi Name Generator (Linguistically Grounded)
*For speakers of the Thaleshi River basin and coastal territories. All names derive from A Polski roots drifted through the full Paltikas lineage (H1 → H2 → H3 → H4) with four layered influences: Vargku (4500 BCE, French-derived fricativization), Buywn (1525 BCE, Welsh consonant mutation), Vepalik (1500 BCE, Hindi vowel lengthening), and Moralin (100 BCE, Romance cluster smoothing). Thaleshi exhibits endonymic stability with flattened stress, simplified clusters, and distinctive initial consonant mutations—audibly distinct from all neighboring languages.*

  • Minimum 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`)

  `ə` (schwa, "uh") > `e` > `i`  
  *Example: Pstrk → Pstərk → "Psterk"*

#### CRITICAL RULES
1. **Welsh Mutation Trigger**: Initial voiceless stops (`P-`, `T-`, `K-`) become fricatives (`F-`, `Th-`, `Kh-`) when preceded by a vowel-final word in compounds:  
   `a + Kar` → `a Far` (not *a Kar*)  
   *Applies ONLY in multi-word phrases, not within single names*

2. **Vowel Length Preservation**: Long vowels (`aː`, `eː`, `iː`, `oː`, `uː`) resist reduction in penultimate syllables. Short vowels reduce to schwa (`ə`) in unstressed positions:  
   `Fenar` → **Fenar** (penultimate `a` preserved as long vowel)  
   `Fenara` → **Fenəra** (final `a` reduces to schwa in rapid speech)

3. **Cluster Simplification Cascade**: Complex clusters reduce in strict order:  
   `CC` → `C` (e.g., `st` → `s`)  
   `CCC` → `CC` → `C` (e.g., `str` → `sr` → `s`)  
   *Exception: Liquid clusters (`pl`, `bl`, `pr`, `br`, `tr`, `dr`) resist simplification due to Moralin influence*

4. **Final Consonant Weakening**: Word-final stops weaken progressively:  
   `p t k` → `b d g` → `β ð ɣ` → `∅`  
   *Example: `kap` → `kab` → `kaβ` → `ka`*

5. **Duplicate Letter Dropping**:  
   `tt` → `t`, `aa` → `a`, `rr` → `r`  
   *Exception: Long vowels marked orthographically with macron (`ā`) retain length marker: `aa` → `ā`*

6. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`). If violated after all rules, insert flow insertion `ə` before final consonant.

#### WHY THESE WORK LINGUISTICALLY
- **Fān**: Reflects A Polski *święty* (holy) → Thaleshi drift `/ɕfjɛntɨ/` → `/faːn/` via Welsh mutation (`/ʃ/` → `/f/`) + Hindi vowel lengthening (`/ɛ/` → `/aː/`). Qua would produce **Shen** (/ʃɛn/); Coro **Khen** (/xɛn/); Stask **Tharen** (/ʈarɛn/).
- **Kār**: From *król* (king) → `/krul/` → Thaleshi `/kaːr/` via vowel backing (`/u/` → `/a/`) + nasal → liquid shift (`/l/` preserved). Coro would produce **Krar** with velarization (`/xrar/`); Qua preserves `/kr/` cluster (`/krar/`).
- **Ēlen**: From *święty las* (holy forest) → `/ɕfjɛntɨ las/` → Thaleshi `/ɛːlɛn/` via cluster simplification (`/ʃfj/` → `/ɛ/`) + vowel lengthening (`/a/` → `/ɛː/`). Unique Thaleshi pattern—neither Qua nor Coro exhibit this degree of cluster collapse.
- **Ūrill**: From *rzeka* (river) + *uzdrowić* (heal) → `/ʐɛka uzdrɔvit͡ɕ/` → Thaleshi `/uːril/` via liquid preservation (`/r/` dominant) + vowel lengthening (`/u/` → `/uː/`). Audibly distinct from Qua's **Urill** (/uril/), Coro's **Khurill** (/xuril/), and Stask's retroflex **Dhurill** (/ɖuril/).
