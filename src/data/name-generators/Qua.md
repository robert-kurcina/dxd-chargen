### Qua Name Generator (Linguistically Grounded)
*For speakers descended from the R1 Qua lineage near the Qua River basin. All names derive from A Polski roots drifted through the Paltikas line (H1 Paltikas → J1 Korsik → R1 Qua) with minimal external influence. Qua preserves Slavic consonant clusters lost in neighboring languages due to its relative isolation after 600 BCE.*

---

#### CORE MECHANICS
- Roll **D66** to determine naming pattern
- For each word part, roll **D66** for the part + **D6** for semantic domain
- Apply either **one Referent Suffix** or **one Morphological Suffix**, not both
- Apply constraints after assembly:
  • Drop duplicate letters (`tt` → `t`, `aa` → `a`)
  • Max 2 consecutive vowels (drop earlier vowels)
  • Minimum 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`)
- **Flow Insertions** (applied ONLY when CCC/CCCC clusters occur):
  `ə` (schwa, "uh") > `i` > `u`  
  *Example: Strzh → Strəzh → "Strezh"*

#### CRITICAL RULES
1. **Vowel-Consonant Reversal**: If assembly exceeds 3 syllables, reverse ONLY the final syllable before suffix:  
   `Strar + -en` → `Straren` → `Straren` (not *Straren* → *Straren*)  
   *Mirrors Qua's stress-driven vowel shifts from Slavic mobile stress.*

2. **Duplicate Letter Dropping**:  
   `tt` → `t`, `aa` → `a`, `rr` → `r`  
   *Example: Strar → Star*

3. **Consecutive Vowels**: Max 2 consecutive vowels; drop earlier vowels:  
   `aia` → `ia`, `ouo` → `uo`  
   *Ending `y` counts as vowel: `ay` → `a` if preceded by vowel*

4. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`). If violated, insert flow insertion `ə` before final consonant.

#### WHY THESE WORK LINGUISTICALLY
- **Stror**: Reflects A Polski *stróż* (guard) → Qua drift `/struʐ/` → `/str/` via final consonant loss + vowel reduction. Preserves Slavic `/str/` cluster lost in Coro (`strah`).
- **Krar**: From *król* (king) → `/krul/` → Qua `/krar/` via vowel epenthesis. Coro would produce `Krar` with Germanic hardening (`/kr/` → `/xr/`).
- **Enshen**: From *święty* (holy) → `/ɕfjɛntɨ/` → Qua `/ɛnʃɛn/` via palatalization preservation. Coro would produce `Enkhen` via Eupiri velarization (`/ʃ/` → `/x/`).
- **Urill**: From *rzeka* (river) + *uzdrowić* (heal) → `/ʐɛka uzdrɔvit͡ɕ/` → Qua `/uril/` via retroflex loss + cluster simplification. Coro would produce `Oril` via vowel centralization.

#### GM NOTES: LINGUISTIC AUTHENTICITY
1. **No English respelling**: All forms derive from Polish cognates drifted through Qua lineage (e.g., *Stror* not "Storr")
2. **Slavic cluster preservation**: Qua retains `/str/`, `/skr/`, `/pr/` clusters lost in Coro due to Eupiri influence
3. **Retroflex retention**: Qua preserves `/ʂ/`, `/t͡ʂ/` series (orthographically "sz", "cz") where Coro shows palatalization
4. **Asymmetric vowel reduction**: Follows Slavic mobile stress patterns (unstressed vowels → `/ə/`), not Coro's symmetric centralization
5. **Phonotactic enforcement**: Tables exclude illegal Qua clusters (no `/tl/`, `/dl/`, word-final `/ŋ/`)
6. **Distinct from Coro**: Qua `/v/` remains voiced (Coro `/f/`); Qua `/ʃ/` remains palatal (Coro `/x/`); Qua preserves affricates (Coro simplifies to fricatives)
