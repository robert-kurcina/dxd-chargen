### Arikkah Name Generator (Linguistically Grounded)
*For speakers of the Arikkah river valleys and coastal settlements near the Corom delta. All names derive from A Polski roots drifted through the Paltikas-Coromu lineage (A Polski → A" Cherczyka → H1 Paltikas → H2 Paltikas → H'1 Coromu → H'2 Coromu → H" Glisorsen → H"' Arikkah) with layered influences: Vargku (4500 BCE, French fricativization), Tegilan dead substrate (1650 BCE, Tagalog open-syllable bias), and F Aelorac contact (250 CE, Romance vowel smoothing). Arikkah exhibits moderate cluster simplification, vowel centralization to schwa, and final consonant restriction to nasals/liquids—audibly distinct as a contact language with fluid phonotactics.*

#### CORE MECHANICS
- Roll **D66** to determine naming pattern
- For each word part, roll **D66** for the part; use semantic domain only to guide flavor and meaning
- Apply either **one Referent Suffix** or **one Morphological Suffix**, not both:
  • Referent suffixes handle person/object/living distinctions
  • Morphological suffixes handle domain or prestige flavor when you want that instead
- Apply constraints after assembly:
  • Drop duplicate letters (`tt` → `t`, `aa` → `a`)
  • Max 2 consecutive vowels (drop earlier vowels)
  • Minimum 2 syllables OR 1 syllable with diphthong (`ya`, `yu`, `oi`, `au`)
- **Flow Insertions** (applied ONLY when CCC/CCCC clusters occur):
  `ə` (schwa, "uh") > `a` > `e`  
  *Example: Kstrk → Kstərk → "Ksterk"*

#### CRITICAL RULES
1. **Duplicate Letter Dropping**: `tt` → `t`, `aa` → `a`, `rr` → `r`.
2. **Nasal Flavor Preservation**: If a result naturally produces `an/en/in/on/un` near the end, feel free to read it with nasal color (`ã ẽ ĩ õ ũ`) rather than adding more derivation.
3. **Final Repair**: If a result ends in a stop or harsh fricative, soften it toward a nasal or liquid.
4. **Minimum Syllables**: Must have 2 syllables OR 1 syllable with diphthong. If violated, insert schwa before final consonant.
5. **Keep It Table-Ready**: Do not apply extra hidden derivations beyond these rules during play.

#### WHY THESE WORK LINGUISTICALLY
- **Khẽn**: Reflects A Polski *chleb* (bread) → Arikkah drift `/xlɛp/` → `/xɛ̃/` via vowel reduction (`/ɛ/` → `/ə/`) + nasalization (`/əp/` → `/ɛ̃/`) + F Aelorac smoothing. Qua would produce **Khen** (/xɛn/ with palatal fricative); Coro **Khen** (/xɛn/ with velarization); Thaleshi **Khen** (/xɛn/ with Welsh mutation); Boren **Khā'k** (/xɛːʔk/); Sarek **Chen** (/xɛn/); Kahadi **Khãr** (/xãɽ/); Ershthikal **Khã́n** (/xã́n/); Ithuuikal **Chẽn** (/xɛ̃n/); Cher-gulo **Khā́n** (/xā́n/).
- **Kãn**: From *kamień* (stone) → `/kamʲɛɲ/` → Arikkah `/kãn/` via Tegilan nasalization (`/mʲ/` → `/m/` → `/ã/`) + F Aelorac vowel smoothing (`/ɛ/` → `/ə/` → deletion). Unique Arikkah pattern—nasalization without full open-syllable enforcement (unlike Cher-gulo) but more than non-contact languages.
- **Ẽɾũ**: From *święty rzeka* (holy river) → `/ɕfjɛntɨ ʐɛka/` → Arikkah `/ɛ̃ɾũ/` via nasalization cascade (`/ɛ/` → `/ɛ̃/`, `/ɛ/` → `/ũ/`) + Tegilan liquid shift (`/ʐ/` → `/ɾ/`) + F Aelorac smoothing. Audibly distinct due to pervasive nasalization + liquid preservation—no other language combines these features with Romance smoothing.
- **Ũnim**: From *rzeka* (river) + *uzdrowić* (heal) → `/ʐɛka uzdrɔvit͡ɕ/` → Arikkah `/ũnim/` via Tegilan nasalization (`/ɛ/` → `/ũ/`, `/i/` → `/ĩ/`) + F Aelorac smoothing (`/zdr/` → `/zim/` → `/nim/`). Only Arikkah exhibits this combination of nasalization + Romance smoothing + moderate cluster simplification.

#### GM NOTES: LINGUISTIC AUTHENTICITY
1. **No English respelling**: All forms derive from Polish cognates drifted through Paltikas-Coromu lineage with layered influences (e.g., *Khẽn* not "Ken")
2. **Contact-language phonology**: Nasalization + schwa reduction + liquid preservation creates "fluid" quality absent in conservative languages (Sarek) or rigidly structured ones (Cher-gulo)
3. **Layered influence visible**: Vargku fricatives preserved initially; Tegilan nasalization dominant medially; F Aelorac smoothing evident in vowel harmony—audible stratigraphy of contact history
4. **Final consonant restriction**: Word-finally only nasals/liquids permitted—immediate auditory marker of Tegilan substrate absent in Qua/Coro/Thaleshi/Sarek/Boren
5. **Schwa dominance without rigidity**: Unstressed vowels reduce to schwa but nasalization blocks reduction—creates rhythmic alternation distinct from Heimneshi's uniform schwa or Sarek's mobile stress
6. **Phonotactic enforcement**: Tables exclude illegal Arikkah finals (no stops/fricatives word-finally); permitted finals strictly `/m n ɲ l ɾ j w/`
7. **Distinct from neighbors**: Arikkah `/xɛ̃/` (nasalized fricative) vs. Qua `/ʃɛn/` (palatal fricative) vs. Coro `/xɛn/` (velar fricative) vs. Thaleshi `/faːn/` (labial fricative + length) vs. Boren `/xɛːʔk/` (glottalized) vs. Sarek `/xɛn/` (alveolar nasal) vs. Kahadi `/ʈʰɛɳ/` (retroflex) vs. beatified languages' frozen forms
