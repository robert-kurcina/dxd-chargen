# CANON SYNC v100 — Character Generator Data Integrity

This release integrates the v99 UX foundation with the approved character-generation data-integrity pass.

## Scope

- Existing D66 conlang name generators remain authoritative.
- Kriket source records remain in the project but are omitted from playable character creation until a canonical age-bracket table exists.
- Magic-item source records remain intact; chargen exposes only complete playable entries.
- Heritage packages are normalized from the character workbook into structured grants while retaining Stars/package-value information only as author-calibration metadata.
- Language metadata and the existing name-generator sources are included from the conlang material.
- Relationships, Merchant completion, and detailed demographic modeling remain deferred.
- Deities may be chosen freely.
- Major selectable catalogues receive deterministic runtime `catalogId` values while legacy keys remain intact.

See `docs/DATA_INTEGRITY_v100.md` and `docs/DATA_INTEGRITY_v100_VALIDATION.json` for the data pass.
